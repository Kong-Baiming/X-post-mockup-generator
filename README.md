# X推文截图生成器

一个本地运行的 X 推文截图生成器。可以编辑作者、正文、媒体、引用推文、回复和互动数据，实时预览并导出单条推文或详情页。

![应用界面](docs/editor-concept.png)

## 功能

支持编辑账号、头像、推文正文、认证状态、互动数据、多图排版、视频封面、引用推文、详情页、等功能。

## 本地运行

安装 [Node.js 22.13 或更高版本](https://nodejs.org/)，下载并解压本项目，然后在项目文件夹中打开终端，依次运行：

```bash
npm install
npm run dev
```

终端会显示一个本地网址，通常是 `http://localhost:5173/`。用浏览器打开即可使用。

## 构建与部署

在项目文件夹中运行：

```bash
npm run build
```

构建完成后会生成 `dist` 文件夹。把这个文件夹里的全部内容上传到支持静态网页的托管服务即可。发布前可以在本机运行下面的命令检查构建结果：

```bash
npm run preview
```
